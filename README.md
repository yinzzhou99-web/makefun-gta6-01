**Port Azura Heat** is an original open-world crime game that runs entirely in the browser, offline, from its own files. Rook, a courier who owes the Marlin Crew $5,000 by sunrise, works a sun-soaked coastal grid city of seven-by-seven streets, a boardwalk and a bay: steal cars, run timed courier jobs between gold and green beacons, mug pedestrians, dodge or ditch a five-star wanted system whose cruisers work the grid and ram to box you in, and wash your plates at the chop shop when the heat gets too high. Everything is synthesized live — the city from one seed, the engine, sirens and crashes from WebAudio — with a full HUD, circular minimap, and busted/wasted endings.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
# then open out/game/index.html in a desktop browser
```
